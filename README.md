# 像素生態瓶 Pixel Terrarium

🎮 **[線上遊玩 Live Demo](https://chien521.github.io/idle_game/)**

一款像素風、悠閒步調的寵物養成／放置類瀏覽器遊戲。點開網頁就是一個裝滿小生物的生態瓶，牠們會自己漫遊、配對、繁衍後代，玩家的角色更像是旁觀與偶爾互動的照顧者，而不是需要隨時操作的玩家。

沒有後端伺服器，所有進度都存在瀏覽器的 `localStorage`，設計上以行動裝置瀏覽器為優先（Mobile-first）。

## 特色亮點

- **全像素風美術**：生態瓶、草地、天空、日月星辰、雲朵、天氣粒子、寵物本體全部逐像素繪製（`CanvasTexture` + `NearestFilter`），沒有任何平滑漸層。
- **沒有懲罰機制**：沒有寵物死亡、沒有資源匱乏的失敗狀態。族群滿員時用「元老退場」讓最老的個體自然讓位給新生兒，維持生態瓶的新陳代謝，而不是卡住或逼玩家做取捨。
- **有血緣的家族樹圖鑑**：不只是外形分類收集，而是完整記錄每一隻歷來出生過的個體與牠們的親子關係，可以在圖鑑裡點開任一隻，用虛線直接看到牠的祖先與子孫。
- **會隨時間變化的世界**：晝夜循環、四季更迭、天氣系統、裝飾物會自己生長／氾濫，同一個生態瓶在不同時間點造訪會看到不同的樣貌。
- **稀有天氣與彩蛋**：雨後偶爾出現的彩虹、晴朗夜晚偶爾出現的流星雨、不定期飄進生態瓶裡外形完全不像一般寵物的神秘小訪客——都會被記錄進圖鑑的隱藏收藏成就。

## 操作方式

畫面下方是主要操作列：

| 操作 | 說明 |
| --- | --- |
| **點擊寵物** | 摸摸互動（有冷卻時間，會累積「陪伴天數」），同時打開該寵物的資訊卡片，可以在卡片裡幫牠改名字 |
| **🍎 餵食** | 按一下進入放置模式，之後每次點草地就丟一份食物；附近的寵物閒晃時有機會注意到並走過去吃掉，可連續放置多份，再按一次按鈕退出模式 |
| **🎁 收藏** | 列出所有裝飾物的解鎖狀態與進度（用「陪伴天數」解鎖，越常互動解鎖越快）。已解鎖的裝飾物沒有使用次數限制，點「🧭 放置一個」就能再放一份到場景裡 |
| **📖 圖鑑** | 顯示歷來出現過的每一隻個體，依「輩分」由上到下分列；點任一隻頭像會用虛線標出牠的祖先（藍框）與子孫（粉框）。上方另外有一區列出稀有天氣／彩蛋等隱藏收藏成就的達成進度 |
| **速度切換（1x/4x/20x）** | 調整模擬推進速度，方便快轉觀察生態瓶的長期變化 |
| **匯出存檔** | 把目前存檔匯出成 JSON 檔案下載 |
| **🔄 重新開始** | 清空所有進度重新來過（有確認對話框，動作無法復原） |

已放置在場景中的裝飾物也可以再次點擊「拿起來」（會變半透明並跟著游標/手指移動），接著點草地上任何位置放下，藉此重新調整擺放位置。

## 核心機制

### 基因與外形
每隻生物都有一組基因：四種外形原型（圓／三角／方潤／菱角，用 superformula 極座標公式決定剪影）加上稀有變異、四種元素傾向（向陽 / 喜濕 / 耐風 / 向陰，強度各自獨立不互斥）、以及色相/體型/速度等視覺特徵。

### 繁殖：一夫一妻制
- 場上的個體會依相容度（元素傾向差異越大、相容度越高）自然配對成伴侶，只有**同一輩分**的個體才能配對。
- 已配對的伴侶隨時間逐漸累積繁殖機率，**每對伴侶最多生育 3 個子女**，且同一對伴侶生出的子女彼此之間外形分類與色系一定不同（可以跟父母相同）。
- 子女的顏色**完全隨機**產生、不繼承父母色相——避免小族群裡顏色隨世代遺傳漂變、越來越集中到少數色系。
- 全域有一道「一天一則新聞」式的生育節奏限制：不管場上有幾對伴侶，同一時間只會有一場新生命誕生，避免爆炸性繁殖。

### 族群與圖鑑
- 族群數量有上限（可透過解鎖「迷你溫室擴建」提高上限），滿員時新生兒誕生會讓最年長的個體（正在生育的那一對除外）自然退場，牠的伴侶會變成「鰥寡」狀態、可以再重新配對。
- **圖鑑會記錄歷來出現過的每一隻個體**，不會因為退場而消失，並保留完整的親子關係，可以在圖鑑裡追溯完整家族樹。

### 互動與解鎖
- **摸摸**與**餵食**（成功餵到）都會累積額外的「陪伴天數」，加速解鎖裝飾物與圖鑑收藏項目。
- 圖鑑收藏項目包含稀有變異個體、四維元素傾向皆出現過、以及下方稀有天氣/彩蛋等隱藏成就。

### 裝飾物系統
可解鎖的裝飾物：苔石、彩色底沙、小水車、營火、水池、椰子樹。解鎖後沒有使用次數限制，可以無限次放置、也能事後拿起來移動位置。部分裝飾物會隨時間演變：

- 🌴 **椰子樹**會從幼苗逐漸長高，約 3 個遊戲日長到成熟大小。
- 💧 **水池**每隔約 3 個遊戲日會有機會短暫氾濫、範圍略為擴大。
- 寵物逗留在裝飾物旁時會有專屬小動畫：苔石蹲坐、彩沙扭動、水車跳動，營火旁會冒出取暖的白霧，水池旁會有戲水濺起的水花。

### 晝夜、四季與天氣
- **晝夜循環**：天空顏色、日月位置隨遊戲時間連續變化。
- **四季循環**（春／夏／秋／冬，約每季 3 個遊戲日）：草地色調隨季節平滑過渡；春天地上會開出像素小花、秋天鋪滿楓紅落葉、夏天有半透明陣風定期掃過畫面。
- **天氣系統**：春夏偶爾下雨、冬天更常飄雪、秋天固定持續飄落葉；夏天雷雨時還有機率出現間歇性閃電。所有天氣與四季都是遊戲時間的決定性函式，重新整理或離線結算都能正確算出當下狀態，不需要額外存檔欄位。

### 稀有天氣與彩蛋訪客
- 🌈 **彩虹**：春夏白天雨停前後，小機率出現。
- ☄️ **流星雨**：晴朗夜晚，小機率出現，好幾顆流星錯開時間劃過夜空。
- ✨ **神秘小訪客**：外形跟一般寵物完全不同（不參與基因/繁殖系統）的稀有訪客，大約每 7 天有機會出現一次、停留一段時間後就離開；需要玩家**主動點擊牠**才會被記錄進圖鑑，比被動看到更有「發現彩蛋」的感覺。

## 技術棧

- **Vite + TypeScript**（strict 模式）
- **Three.js**：`OrthographicCamera` + `Sprite` / `CanvasTexture`，純程式繪製像素圖，不使用外部美術素材
- 存檔以版本化的 JSON 結構存在瀏覽器 `localStorage`，並針對舊版存檔缺少的欄位做相容遷移；登入 VIVERSE 帳號後會額外同步到雲端存檔（見下方）
- 相機採「以高度為準」的框取策略，直向手機畫面會裁切左右兩側、橫向畫面則會在左右露出黑邊，確保草地與天空永遠完整可見
- 多語系：`_htc_lang_code`（VIVERSE 語言 cookie）／`?lang=`／瀏覽器語言，支援 繁中／简中／英文／日文／韓文／西班牙文

## 開發方式

```bash
npm install
npm run dev      # 啟動開發伺服器
npm run build    # tsc -b && vite build，輸出到 dist/
```

本地開發用 `?lang=en`、`?lang=ja`、`?lang=ko`、`?lang=es`、`?lang=zh-CN` 這種網址參數切換語言測試（本機沒有 VIVERSE 的 `_htc_lang_code` cookie，這是官方建議的測試方式）。

VIVERSE 登入/雲端存檔在本機（無 HTTPS、沒有已註冊的 redirect URI）本來就會逾時，程式已經設計成失敗就自動回退成訪客模式，不影響本地開發跟遊玩。

## 發布到 VIVERSE

App ID（`VITE_VIVERSE_CLIENT_ID`）已經寫在 `.env` 裡（不會進版控，`.env.example` 有佔位範本）。以下步驟需要你自己的 VIVERSE 帳號，請自行在瀏覽器完成：

```bash
npm install -g @viverse/cli
viverse-cli auth login          # 瀏覽器跳出登入頁，用你的 VIVERSE 帳號登入
npm run build                   # 產生 dist/，App ID 會在 build 時注入進去
viverse-cli app publish ./dist --app-id kjkr394chg
```

發布成功後會回傳一個 `https://worlds.viverse.com/...` 的網址。之後要更新版本，重新 `npm run build` 再跑一次 `viverse-cli app publish` 即可，同一個網址會直接被覆蓋更新。

發布後務必到那個網址實測一次：確認能點擊互動（摸摸/餵食/裝飾放置）、登入按鈕能正常導向 VIVERSE 登入、登入後存檔有正確同步到雲端。
